# RTP Play Legendado

A reference list of the programmes on [RTP Play](https://www.rtp.pt/play/) that carry a Portuguese
subtitle track, built for learners of European Portuguese who want comprehensible input.

The page (`index.html`) is a single self-contained file: no build step, no dependencies, no tracking.
Open it locally or serve it from GitHub Pages.

## What's in it

- **649 programmes** with a Portuguese subtitle track, out of 6,268 TV programmes in the RTP Play
  catalogue, checked on 11 September 2026.
- Grouped by genre, with series, films, entertainment, documentaries, magazines and children's
  programmes separated, and foreign-language material kept at the bottom.
- **English translations** of every title and description, which can be hidden to read the Portuguese
  cold first.
- A filter that hides titles which return *SEM DIREITOS DE TRANSMISSÃO ONLINE* — RTP's rights check
  refuses them outside Portugal.
- Show-level descriptions for series and recurring programmes; latest-episode descriptions elsewhere.

## How it was built

Each programme's latest episode page was checked for a subtitle file in the player configuration
(RTP labels the track *Português adaptado*, i.e. captions for deaf and hard-of-hearing viewers).
Playability was checked against RTP's own rights service.

## Caveats

- Only the latest episode of each programme was checked, so a show may have subtitles on some
  episodes and not others.
- Streaming rights depend on the viewer's country and change over time.
- For foreign-language films and series the Portuguese subtitles are a translation, not a
  transcription of the audio — useful for reading, not for listening.
- RTP's catalogue changes constantly; treat the list as a snapshot.

Data belongs to RTP – Rádio e Televisão de Portugal. This page only links to their pages.
